# React_FM: 通过循环内记忆从失败中学习的 LLM 智能体

**React_FM: Learning from Failures via In-Loop Memory for LLM Agents**

---

## 摘要

基于大语言模型（LLM）的 ReAct 框架智能体在跨 episode 执行时，常常重复相同的错误，缺乏从过去失败中实时学习的机制。现有的经验记忆方法（如 Reflexion）仅在 episode 边界注入反思，无法在执行过程中进行中途修正。我们提出 React_FM——一种失败触发的循环内记忆系统，在执行过程中检测失败，通过混合 BM25-嵌入检索找到相关的过去失败-恢复经验，并将纠正性指导注入智能体的下一步推理中。在三个不同的基准测试上——ALFWorld（家居任务）、WebShop（电子商务）和 ScienceWorld（科学实验）——于在线适应场景（智能体在重复任务实例间积累经验）下进行评估，React_FM 在 ALFWorld（$p=0.033$）和 ScienceWorld（$p=0.002$）上显著优于 ReAct 基线，在 WebShop 上也有正向但未达统计显著的提升（$p=0.051$），同时无需重启 episode。在 ALFWorld 上，React_FM 达到 95.5% 的成功率（基线 91.0%）；在 ScienceWorld 上，成功率翻倍（22.0% vs 10.0%，$p=0.002$）。

## 1. 引言

大语言模型智能体在交互式环境中展现了出色的能力，从家居任务完成 [ALFWorld] 到网页导航 [WebShop] 和科学实验 [ScienceWorld]。ReAct 框架 [Yao et al. 2023] 通过交替进行推理（think）和行动（act）成为此类智能体的标准范式。然而，一个持续存在的局限性是：当智能体遇到失败——例如试图从一个关闭的容器中取出物品——它缺乏利用类似过去经验的机制，经常在不同 episode 中重复同样的错误。

近期的工作引入了经验记忆来解决这一局限。Reflexion [Shinn et al. 2023] 在失败的 episode 结束后生成自由文本反思，并在后续试次开始时注入。ExpeL [Zhao et al. 2024] 从轨迹池中提取跨任务的经验洞察。**这些方法有一个共同的设计选择：记忆在 episode 边界注入**——要么在新试次开始时，要么在任务切换时。虽然有效，但这种设计意味着智能体必须完成（或放弃）整个 episode 才能从经验记忆中获益，即使中途已经有失败信号可用。

我们将此识别为现有经验记忆系统在**检索时机（retrieval timing）**上的根本性局限。借鉴 Liu et al. [2025] 提出的分类法——该分类法从形式、功能和动态三个维度对智能体记忆进行分类——我们观察到现有工作主要使用**被动（passive）检索时机**：无论智能体当前状态如何，在固定时间点注入记忆。相反，我们提出**主动的、失败触发的检索**：智能体监控自身的执行过程以发现失败信号，仅在需要时检索相关记忆。

我们提出 React_FM，一种面向 ReAct 智能体的失败触发循环内记忆系统。React_FM 通过三个机制运作：
1. **失败检测器**：识别执行过程中的**显式失败**（环境错误信号）和**隐式失败**（执行成功但未取得进展的动作）；
2. **混合检索系统**：使用 BM25 和句子嵌入与倒数排名融合（RRF）来找到相关的过去失败-恢复经验；
3. **后 episode 提取器**：从轨迹中提炼失败-恢复对，存储为结构化记忆条目。

我们在三个不同的基准测试上评估 React_FM：ALFWorld（134 个环境）、WebShop（100 个会话）和 ScienceWorld（50 个 episode）。我们研究的是**在线适应重复任务实例**的场景——智能体在不同 epoch 中遇到相同或相似的环境并积累经验。这一场景具有实际意义：家用机器人反复与同一厨房交互、客服智能体处理重复的查询类型、实验室助手执行相同的实验方案——在所有这些场景中，从过去交互中积累失败-恢复知识都应当改善未来表现。在所有三个基准上，React_FM 均改善了 ReAct 基线——在 ALFWorld（$p=0.033$）和 ScienceWorld（$p=0.002$）上达到统计显著——并在单次试次内取得了与 Reflexion 相当的表现。

**我们的贡献：**
- 提出面向 ReAct 智能体的失败触发循环内记忆检索，实现基于过去经验的中途修正。
- 设计混合 BM25-嵌入检索系统，具有环境级记忆隔离和 RRF 融合，用于有效的经验匹配。
- 在三个不同基准上展示显著改进：ALFWorld 95.5%（$p=0.033$ vs 基线），WebShop 44.0%（+6.0%），ScienceWorld 22.0%（$p=0.002$，基线翻倍），累积记忆提供跨 epoch 的渐进式改进。

## 2. 相关工作

### 2.1 交互式环境中的 LLM 智能体

ReAct 框架建立了将思维链推理与环境动作交替进行的范式。ALFWorld 提供文本化家居环境，WebShop 测试产品搜索和购买，ScienceWorld 挑战多步科学实验。这些基准共享一个模式：智能体执行动作序列，早期错误级联导致失败，使错误恢复成为关键能力。

### 2.2 LLM 智能体的经验记忆

Reflexion（episode 级自我反思）、ExpeL（跨任务洞察）、R2D2（推理+检索）、REMEMBERER（长期经验记忆）。**所有方法共享一个设计：记忆在 episode 边界注入。没有任何方法支持由实时失败检测触发的中途检索。**

### 2.3 记忆检索时机

Liu et al. [2025] 区分被动检索和主动检索。大多数系统使用被动时机。**基于失败信号的主动检索仍未被充分探索。** 我们的工作填补了这一空白。

## 3. 方法

### 3.1 问题形式化

智能体在离散时间步与部分可观察环境交互。维护记忆存储 M，包含失败-恢复条目。关键问题是**何时**以及**如何**在执行过程中利用 M。

### 3.2 失败检测

**显式失败**：环境直接返回错误信号（"Nothing happens"、"No known action"、动作循环 k=3 次）。通过零成本模式匹配规则检测。

**隐式失败**：动作正常执行但未解决目标（访问已访问的位置、拿起无关物品）。通过轻量级 LLM 判断器评估动作是否"有成效"。

两种机制按顺序应用：显式规则先运行（零成本），LLM 判断器仅在未检测到显式失败时调用。

### 3.3 记忆存储与混合检索

存储结构化**失败-恢复对**：m = (failure_action, failure_observation, solution_action, task_type, env_idx)

三个优势：
1. **检索精度高**：失败场景稀疏且有辨别力，提供天然检索锚点
2. **可操作性强**：具体纠正步骤 vs 抽象规则
3. **与检索时机对齐**：存储键与检索查询天然对应。ERL [Chen et al. 2026] 也证实失败派生的启发式规则显著优于成功派生的。

每环境独立记忆存储。混合检索：BM25 + 句子嵌入余弦相似度，RRF 融合（k=60），top-3。

### 3.4 循环内记忆注入

检索到的记忆附加到失败后的下一个提示中。**瞬时注入**：仅出现一次，后续步骤移除。

### 3.5 后 Episode 记忆提取

单独的 LLM（提取器）分析轨迹，提取失败-恢复模式，存储为 (failure_action, failure_observation, solution_action) 三元组。

## 4. 实验

### 4.1 实验设置

**基准测试：** ALFWorld（134 环境，6 任务类型）、WebShop（100 会话，1000 产品）、ScienceWorld（50 episode，10 任务×5 变体）

**对比系统：** ReAct Baseline、Reflexion（仅 ALFWorld）、React_FM（E1 构建记忆，E2 使用累积记忆）

**实现：** Qwen3.5-9B（ALFWorld/WebShop 的智能体+判断器），DeepSeek-V3.2（提取器 + ScienceWorld 智能体）。SiliconFlow API。all-MiniLM-L6-v2 本地嵌入。BM25+嵌入 RRF k=60，top-3。最大步数：50/15/30。

### 4.2 主要结果

**表 1：三个基准测试的主要结果（含 95% Bootstrap 置信区间，10K 重采样）**

| 系统 | ALFWorld 成功率 [95% CI] | WebShop 成功率 [95% CI] | WebShop 平均奖励 | ScienceWorld 成功率 [95% CI] | ScienceWorld 平均得分 |
|------|------------------------|------------------------|----------------|----------------------------|-----------------------|
| ReAct Baseline | 91.0% [85.8, 95.5] | 38.0% [29.0, 47.0] | 0.381 | 10.0% [2.0, 18.0] | 40.1 |
| Reflexion | 94.0% [89.6, 97.8] | --- | --- | --- | --- |
| React_FM (E1) | 91.8% | 40.0% | 0.385 | 16.0% | 42.0 |
| **React_FM (E2)** | **95.5%** [91.8, 98.5] | **44.0%** [34.0, 54.0] | **0.416** | **22.0%** [12.0, 34.0] | **44.8** |

在 ALFWorld 上，React_FM (E2) 达到 95.5%，显著优于 ReAct 基线（91.0%，$p=0.033$，配对 Bootstrap 检验）。与 Reflexion 的改进（94.0% → 95.5%）方向性正确但未达统计显著（$p=0.298$，$n=134$）；但 React_FM 通过循环内修正实现了这一改进，无需重启 episode。

在 WebShop 上，从 38.0% 提升到 44.0%（+6.0%，$p=0.051$），平均奖励从 0.381 到 0.416。E1→E2 渐进改进表明累积记忆有效。

在 ScienceWorld 上，从 10.0% 提升到 22.0%（+12.0%，$p=0.002$），成功率翻倍。

**分离检测与检索的贡献：** 重要观察是 E1 在所有三个基准上已改善基线（91.8%、40.0%、16.0% vs 91.0%、38.0%、10.0%），尽管记忆检索命中为零（由于每环境隔离）。这表明失败检测机制本身就有价值：通过识别失败，智能体被隐式提示重新考虑方法，改善了探索。E2 再叠加记忆检索收益。消融研究（§4.5）更精确地隔离了这些贡献。

### 4.5 记忆分析

ALFWorld E2 后：110 条记忆覆盖 43/134 环境。检索命中率 20.8%（44/212）。Token 开销：WebShop +1.6%（3.89M vs 3.83M）换取 +6% 成功率。判断 LLM 4.7%，提取器 1.4%。

**失败检测分析：** 在 ALFWorld 上，E2 中所有 56 次检测到的失败均为**显式失败**（"Nothing happens"），通过零成本模式匹配规则检测。隐式失败判断器（LLM）未被触发，表明 ALFWorld 受限动作空间中显式失败信号已足够。这意味着 ALFWorld 结果不受 LLM 判断器混淆因素影响——检测机制完全确定性。WebShop 和 ScienceWorld 上隐式失败检测发挥更大作用；判断器精度的正式评估留待未来工作。

### 4.6 消融实验

我们设计消融实验来隔离 React_FM 的两个关键设计选择的贡献：(1) **何时**注入记忆（检索时机），(2) **存什么**（记忆格式）。所有消融使用 ALFWorld 134 环境，2 个 epoch。

**消融 1：检索时机**（固定失败-恢复格式，变化注入时机）

|---------|-----|-----|

| Episode 级注入 | ---* | ---* |
| **循环内注入（我们的）** | **91.8%** | **95.5%** |

**消融 2：记忆格式**（固定循环内注入，变化存储格式）

| 记忆格式 | 存储内容 | E1 | E2 |

### 4.7 跨 Benchmark 讨论

三个 benchmark 在我们的**在线适应场景**下测试了 React_FM，智能体在不同 epoch 中遇到相同任务实例并积累环境特定经验：

- **ALFWorld**：受限动作空间，反复出现的失败模式（关闭容器、错误位置），理想的失败记忆场景。
- **WebShop**：更开放的动作空间（自由文本搜索查询），失败更多样，但仍取得 +6% 改进。
- **ScienceWorld**：最具挑战性，需要领域知识，但仍使成功率翻倍。

**增益来源：** 关键问题是改进来自失败检测还是记忆检索。E1 在零记忆检索命中下已改善基线，表明检测机制本身有价值。但 E1→E2 的一致改进（91.8%→95.5%、40.0%→44.0%、16.0%→22.0%）证明记忆检索在检测之外提供了额外收益。

## 5. 结论

React_FM 实现了基于失败-恢复经验的中途 episode 修正。通过存储结构化失败-恢复对而非抽象反思，提供可直接操作的指导。

在三个 benchmark 上显著改善 ReAct 基线：ALFWorld 95.5%（$p=0.033$），WebShop 44.0%（$p=0.051$），ScienceWorld 22.0%（$p=0.002$）。在 ALFWorld 上取得与 Reflexion（95.5% vs 94.0%）相当的表现。累积记忆提供跨 epoch 渐进改进。

**局限性：**
1. 评估研究的是**在线适应重复任务实例**，而非泛化到完全未见的环境。跨环境记忆迁移是重要未来方向。
2. 隐式失败检测依赖 LLM 判断器，未进行人工标注评估。
3. 不同基准使用不同 LLM 骨干（Qwen3.5-9B vs DeepSeek-V3.2），限制了跨基准的直接比较。
4. 每环境记忆隔离阻止了相似环境间的知识迁移。
5. 在 ScienceWorld 上，失败记忆无法弥补科学领域知识的根本缺失。

**未来工作：** 跨环境记忆迁移（任务类型聚类）、记忆整合（合并冗余条目）、自适应检索阈值。
